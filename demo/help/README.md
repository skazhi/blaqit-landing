# Скриншоты для базы знаний (вкладка «Помощь → Инструкции по разделам»)

Кладите PNG сюда. В статьях они подключаются блоком `{ t: 'img', src: '/help/<имя>.png', pins: [...] }`
в файле `src/config/help.ts`. Стрелки-номера (pins) задаются в процентах от размера картинки.

## Как снимать (не руками!)

Скриншоты снимаются скриптом `scripts/help-shots.mjs` с **витрины** (демо-режим), где
все данные выдуманы (`src/demo`). Это не удобство, а требование: настоящие ПД жильцов —
паспорта, ФИО, телефоны — не должны попасть в картинку, а она уезжает в репозиторий и
расходится по всем копиям продукта. Снимать экраны боевой CRM нельзя даже «на тестовом
жильце»: рядом в кадре окажутся живые.

Витрина живёт в `main` (отдельной ветки `demo` больше нет), поэтому всё из `crm_frontend`:

```
npm run dev:demo -- --port 5188 --strictPort &
node scripts/help-shots.mjs
```

Переменные: `DEMO_URL` (адрес витрины, по умолчанию `http://localhost:5188/demo/`),
`CHROMIUM_PATH` (путь к браузеру, если Playwright не нашёл свой). Скрипт сам печатает
координаты меток — их переносят в `help.ts`.

Дальше пережать (интерфейс — плоские заливки, 256 цветов не отличить, а вес падает
вдвое; Pillow есть в venv бэкенда):

```
python3 -c "
from PIL import Image; import glob
for f in glob.glob('public/help/*.png'):
    Image.open(f).convert('RGB').quantize(colors=256).save(f, optimize=True)"
```

## Тема

Снимаем в **тёмной** теме — это умолчание, её видит новый пользователь. В светлой окна
заселения и правки остаются тёмными «стёклами» (`.glass-modal`) с блёклым текстом, и на
снимке не прочитать.

## Метки на картинке

Номера (`pins`) задаются в процентах от размера картинки — не в пикселях, поэтому не
зависят от того, в каком размере она показана. Скрипт считает их по `boundingBox()` нужной
кнопки, делённому на размер кадра, — подбирать на глаз не нужно.

## Чего в витрине нет

Обход и прачечная в демо-данных пустые — снимок получится с нулями и пустыми списками.
Для них в справке используются рисованные макеты (`{ t: 'mock' }`, разметка в
`src/pages/HelpCenter.tsx`), а не скриншоты.
