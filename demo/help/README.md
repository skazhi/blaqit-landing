# Скриншоты для базы знаний (вкладка «Помощь → Инструкции по разделам»)

Кладите PNG сюда. В статьях они подключаются блоком `{ t: 'img', src: '/help/<имя>.png', pins: [...] }`
в файле `src/config/help.ts`. Стрелки-номера (pins) задаются в процентах от размера картинки.

## Как снимать (не руками!)

Скриншоты снимаются скриптом `scripts/help-shots.mjs` с **демо-режима**, где все
данные выдуманы (`src/demo` на ветке `demo`). Это не удобство, а требование:
настоящие ПД жильцов — паспорта, ФИО, телефоны — не должны попасть в картинку,
а она уезжает в репозиторий и расходится по всем копиям продукта. Снимать
экраны боевой CRM нельзя даже «на тестовом жильце»: рядом в кадре окажутся живые.

```
git worktree add /tmp/demo-shots origin/demo
ln -s "$PWD/node_modules" /tmp/demo-shots/crm_frontend/node_modules
cd /tmp/demo-shots/crm_frontend && npx vite --mode demo --port 4181 &
cd -   # обратно в crm_frontend на main
node scripts/help-shots.mjs
```

Дальше пережать (интерфейс — плоские заливки, 256 цветов не отличить, а вес
падает втрое):

```
python3 -c "
from PIL import Image; import glob
for f in glob.glob('public/help/*.png'):
    Image.open(f).convert('RGB').quantize(colors=256).save(f, optimize=True)"
```

## Метки на картинке

Номера (`pins`) задаются в процентах от размера картинки — не в пикселях,
поэтому не зависят от того, в каком размере она показана. Координаты удобно
не подбирать на глаз, а измерить: у Playwright `boundingBox()` нужной кнопки,
делённый на размер кадра.

## Чего в демо нет

Обход и прачечная в демо-данных пустые — снимок получится с нулями и пустыми
списками. Для них в справке используются рисованные макеты (`{ t: 'mock' }`,
разметка в `src/pages/HelpCenter.tsx`), а не скриншоты.
